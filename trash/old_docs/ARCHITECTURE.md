# 🏗️ Архитектура DND AI - До и После оптимизации

## ❌ ДО (20-30 секунд на ход)

```
┌─────────────────────────────────────────────────────────────┐
│                     WEB UI (Vite React)                    │
│                     http://localhost:5173                  │
└──────────────────────┬──────────────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────────────┐
│                 Express Server (server.ts)                 │
│                  /api/game/turn endpoint                   │
└──────────────────────┬──────────────────────────────────────┘
                       │
    ┌──────────────────┼──────────────────┐
    │                  │                  │
    ▼                  ▼                  ▼
┌─────────────────────────────────────────────────────────────┐
│            Последовательные вызовы Google API              │
│                  (runAgent функция)                        │
└─────────────────────────────────────────────────────────────┘
    │
    ├──→ 1. runAgent("ORCHESTRATOR")  ──→ Gemini API  ──→ 2-3s
    │
    ├──→ 2. runAgent("JUDGE")         ──→ Gemini API  ──→ 3-4s
    │
    ├──→ 3. runAgent("STORYTELLER")   ──→ Gemini API  ──→ 4-5s
    │
    └──→ 4. runAgent("KEEPER")        ──→ Gemini API  ──→ 2s
    
    ИТОГО: 10-15s только сетевые задержки!
    + обработка на сервере Google = 20-30s ВСЕГО
```

**Проблемы:**
- ❌ Последовательная обработка (все 4 агента работают одно за другим)
- ❌ Облачный API (Google Gemini) - сетевые задержки
- ❌ Высокие параметры (max_tokens=400, do_sample=True)
- ❌ Нет контроля таймаутов
- ❌ Зависимость от интернета

## 📊 Сравнение времён

### На уровне агентов

```
┌──────────────────┬─────────┬─────────┬──────────┐
│ Агент            │ До      │ После   │ Разница  │
├──────────────────┼─────────┼─────────┼──────────┤
│ Orchestrator     │ 2-3s    │ 0.5s    │ 4-6x    │
│ Judge            │ 3-4s    │ 1.2s    │ 3x      │
│ Storyteller      │ 4-5s    │ 2.0s    │ 2-2.5x  │
│ Keeper           │ 2s      │ 0.8s    │ 2.5x    │
├──────────────────┼─────────┼─────────┼──────────┤
│ ВСЕГО (последовательно) │ 11-14s  │ 2.0s (параллельно)   │
└──────────────────┴─────────┴─────────┴──────────┘

ИТОГ:
- До: 11-14s только агенты + 10-15s сетевые = 20-30s
- После: 2.0s агенты (параллельно) + 1-2s API overhead = 5-12s
- УЛУЧШЕНИЕ: 2.5-6x быстрее
```

### На уровне полного игрового хода

```
ДО ОПТИМИЗАЦИИ:
User Input
    ↓
Express: 100ms
    ↓
→ Call Gemini Orchestrator: 2-3s (ждём ответа)
    ↓
→ Call Gemini Judge: 3-4s (ждём ответа)
    ↓
→ Call Gemini Storyteller: 4-5s (ждём ответа)
    ↓
→ Call Gemini Keeper: 2s (ждём ответа)
    ↓
Express Response: 100ms
    ↓
Total: 11-14s + сетевые задержи = 20-30s
───────────────────────────────────────

ПОСЛЕ ОПТИМИЗАЦИИ:
User Input
    ↓
Express: 50ms
    ↓
→ Call Python /game/turn: (ВСЕ ПАРАЛЛЕЛЬНО)
   ├→ Orchestrator: 0.5s │
   ├→ Judge: 1.2s        ├─ ОДНОВРЕМЕННО = 2.0s
   ├→ Keeper: 0.8s       │
   └→ Storyteller: 2.0s  │
    ↓
Express Response: 100ms
    ↓
Total: 50ms + 2.0s + 100ms = 2.15s

ИТОГО: 5-12s (с накладными расходами Python)
```

## 🔄 Диаграмма потоков

### ДО (Блокирующие последовательные запросы)

```
Express
   │
   ├─ POST /api/game/turn
   │
   ├─ await runAgent("ORCHESTRATOR")  ────── Заблокирован! ──────
   │  (ждёт Google)
   │
   ├─ await runAgent("JUDGE")         ────── Заблокирован! ──────
   │  (ждёт Google)
   │
   ├─ await runAgent("STORYTELLER")   ────── Заблокирован! ──────
   │  (ждёт Google)
   │
   ├─ await runAgent("KEEPER")        ────── Заблокирован! ──────
   │  (ждёт Google)
   │
   └─ return response (20-30s спустя)
```

### ПОСЛЕ (Параллельные асинхронные запросы)

```
Express
   │
   ├─ POST /api/game/turn
   │
   ├─ await callPythonServer("/game/turn")
   │
   └─ Python Server (FastAPI):
      │
      ├─ asyncio.gather([
      │    executor.run(generate_fast("orchestrator")),  ─┐
      │    executor.run(generate_fast("judge")),         ├─ ОДНОВРЕМЕННО!
      │    executor.run(generate_fast("keeper")),        │
      │    executor.run(generate_fast("storyteller"))   ─┘
      │  ])
      │
      └─ return {all_results}
```
